# App-owned Library with an export hatch

The working set of Projects is an app-owned directory, not a user-picked documents folder. That keeps “open the app and search” as the daily path, at the cost of a hidden copy of truth. Import copies into the Library; Export Project writes a copy out (Transcript, metadata, Source path — not the media). Delete removes the Library copy and never the Source.

**Considered options:** user-chosen folder as the Library; recently-opened files only; app-owned directory with no export (rejected: the Project file would not be backupable).
