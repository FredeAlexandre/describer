# On-device processing only

Describer turns meeting recordings into evidence the owner may later use in a dispute. Cloud speech-to-text would be faster on a weak GPU, but it means accounts, cost, and files leaving the disk — a different product. Processing, diarization, and Voice matching stay on-device; there is no STT API and no upload.

**Considered options:** on-device only (chosen); cloud STT; on-device default with optional cloud later.
